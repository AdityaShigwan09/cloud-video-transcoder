Administrator Privileges Restricted

Standard Users have full upload & video playback access. Admin Login is required to unlock live infrastructure telemetry, SQS queue controls, and AWS bucket diagnostics.

AWS S3
Simple Storage Service

Stores raw uploaded videos and holds transcoded multi-bitrate MP4 renditions and JPEG thumbnail files with high durability.

AWS SQS
Simple Queue Service

Provides a fully managed asynchronous message queue to buffer transcoding jobs and decouple web API servers from compute nodes.

AWS EC2
Elastic Compute Cloud

Hosts background worker nodes that poll SQS, download raw video files, run FFmpeg hardware encoding, and push results back to S3.

AWS CloudFront
Content Delivery Network

Caches transcoded video renditions at global edge locations for ultra-low latency, instant video playback without buffering.

AWS IAM & SigV4
Identity & Presigned Security

Generates short-lived, time-limited presigned S3 URLs allowing direct browser-to-S3 uploads securely without exposing server secrets.

SQLite Database
Embedded Relational Engine

Embedded zero-config database storing video titles, processing statuses, S3 keys, and metadata with Write-Ahead Logging (WAL) speed.

System Architecture Overview

The platform follows a modern, decoupled asynchronous microservices pattern built for high scalability and zero single-point-of-failure.
